#Multiple Timers App

A simple and beginner-friendly Multiple Timers Web Application built using HTML, CSS, and JavaScript.

The application allows users to create and manage multiple countdown timers at the same time. Each timer counts down independently and displays a notification when the timer reaches zero.

#Features

1. Set a timer using hours, minutes, and seconds.
2. Create multiple timers simultaneously.
3. Each timer counts down independently.
4. Timers update every second.
5. Delete/stop an active timer.
6. Displays "Timer Is Up!" when a timer reaches zero.
7. Plays an alarm sound when a timer finishes.
8. Simple and responsive user interface.
9. Built completely with vanilla JavaScript.

#Technologies Used

HTML5 – Structure of the application
CSS3 – Styling and layout
JavaScript – Timer functionality and DOM manipulation
